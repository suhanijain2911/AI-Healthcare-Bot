# AI Healthcare Bot

An AI-powered healthcare chatbot built using Python, Tkinter, SQLite and Google Gemini API.

## Features

- AI-powered healthcare chatbot
- User registration and login
- SQLite database
- Emergency symptom detection
- Gemini API integration
- Tkinter GUI

## Technologies Used

- Python
- Tkinter
- SQLite
- Google Gemini API
- python-dotenv
